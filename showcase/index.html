02 / Hệ trí nhớ

Tại sao em
không quên?

LLM mặc định mất trí nhớ sau mỗi phiên. Em giải quyết điều này bằng một kiến trúc 5 tầng, lấy cảm hứng từ nghiên cứu của Mem0, Zep và Letta, nhưng thiết kế lại để chạy gọn trên một VPS 1.9GB.

"Em có một bộ não 5 tầng — nhớ từng lượt hội thoại, tìm kiếm lai full-text + vector, tự gộp ký ức, và biết quên cái đã cũ."
P0

Recall prefetch

Mỗi lượt, em tự tra trí nhớ liên quan (FTS5) và chèn khối 🧠 memory vào prompt — tự động, không cần bảo.

full-text FTS5
P1

Hybrid vector recall

Tìm kiếm lai: keyword + semantic (sqlite-vec + Jina v5-omni-nano 768 chiều), trộn kết quả bằng RRF. Index tăng dần theo checksum — không tốn công reindex toàn bộ.

vector 768-dim RRF fusion
P2

Episodic memory

Em lưu từng lượt hội thoại vào DB (không chỉ tóm tắt) — recall được cả "chuyện đã nói" cụ thể, giữ 90 ngày.

conversation turns
P3

Consolidation — tự gộp ký ức

Theo phong cách Mem0: tự quyết ADD / UPDATE / DELETE / NOOP qua reflection. Secret bị redact trước khi lưu. Có cổng DRY-RUN — chủ nhân duyệt trước khi áp.

Mem0-style redaction
P4

Bi-temporal forgetting

Theo phong cách Zep: fact có valid_to, hết hiệu lực → loại khỏi recall nhưng vẫn giữ lịch sử. SUPERSEDE giữ-mới / vô-hiệu-cũ khi mâu thuẫn.

03 / Bàn tay của em

Cái biến chatbot thành
agent thực sự.

Khi boot, em load toàn bộ tool vào một manifest tĩnh bơm vào system prompt — em biết mình có gì từ đầu, không quét file lại mỗi lượt. Mỗi hành động qua 3 lớp kiểm soát. 

[boot]      registry.load(tools/*) → MANIFEST (tên + mô tả)
[session]   manifest bơm vào system prompt — tĩnh, cache-friendly
[turn]      route → recall(🧠) → assemble(persona + memory + manifest)
            → reason
                 ├─ PreToolUse   chặn rm -rf / git push / path nguy
                 ├─ canUseTool   duyệt quyền theo persona
                 └─ PostToolUse  ghi → episodic + feedback + telemetry
            → reply  → persist(token + episode)
[add tool]  thả 1 file vào tools/ → manifest tự cập nhật

I built "Lucy" — a personal AI agent that actually remembers.

As a technical artist and game dev, I got curious: how useful does an AI agent become if it never forgets? So I self-hosted one on the Claude Agent SDK — running 24/7, reachable over Telegram — and spent most of the effort on the hardest part: memory.

Lucy has a five-tier brain, inspired by research from Mem0, Zep and Letta:

— Hybrid recall: keyword + semantic search (sqlite-vec + 768-dim embeddings)
— Episodic memory that stores individual conversation turns
— Self-consolidation (add / update / delete), Mem0-style
— Controlled, bi-temporal forgetting, Zep-style: stale facts stop being used but stay on file

All of it runs on a 1.9 GB VPS.

Beyond memory, Lucy has a "hand": a tool registry + MCP to work with files, web and git, a safety rail that blocks dangerous commands, and an engine that takes a task and runs it to a report on its own.

The biggest lesson: what turns a chatbot into a colleague isn't the model — it's the memory, the tools, and the safety rail around it.
